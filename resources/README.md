# Assets de marca para aplicativos nativos

- `icon.png`: origem quadrada 1024x1024 para gerar ícones Android/iOS.
- `splash.png`: origem 2732x2732 para gerar telas de abertura.

Antes de publicação, revisar a zona segura, transparência, formatos e tamanhos solicitados pelas versões atuais das lojas. Gerar os recursos finais nativos com a ferramenta de assets do Capacitor e verificar em aparelhos reais.
